Proyectos Destacados

TecnoStore Desktop

Nace de un problema real de cualquier tienda: perder el control del inventario. Es una aplicación de escritorio en Java (Swing + NetBeans) conectada a MySQL, donde cada usuario entra con un rol distinto y solo ve lo que le corresponde — desde un vendedor hasta un administrador con acceso total. Permite registrar, editar y eliminar productos, avisa automáticamente cuando algo se está agotando, y calcula el valor total del inventario sin que nadie tenga que sacar cuentas a mano. Por dentro está armado con patrones de diseño, pensando en que el código se pueda seguir creciendo sin volverse un caos.

Java Swing MySQL

Aplicacion web para el control de los campeonatos de futbol

Es una aplicación web que digitaliza los campeonatos de fútbol de la I.E. Cristo Obrero, permitiendo registrar los equipos participantes y llevar el control de todo el torneo desde un solo lugar. Maneja dos tipos de acceso: un administrador que puede crear, editar, actualizar y eliminar la información, y un usuario normal que consulta en tiempo real cómo va el campeonato — equipos participantes, calendario de partidos, tabla de posiciones y goleadores etc. Fue mi proyecto de grado de la técnica en Programación de Software con otro Compañero.
